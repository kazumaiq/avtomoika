# AUTOMOIKA — 3D Симулятор Автомойки

Стилизованная браузерная 3D-игра по управлению автомойкой в духе *Spider-Man: Into the Spider-Verse* с живым городским окружением, детализированным многоэтапным процессом мойки, анимированным персоналом, конкурентом **TURBO SHINE** напротив и полноценной экономикой.

## Стек технологий

- **React 19 + TypeScript + Vite**
- **Three.js + React Three Fiber + @react-three/drei**
- **Zustand** для реактивного игрового состояния
- **Framer Motion** для плавных интерфейсных анимаций
- **Web Audio API** — процедурный звук (вода, пена, двигатели, касса, музыка)
- **LocalStorage + IndexedDB** — двойное автосохранение прогресса

## Быстрый старт

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Основные механики

- **Живой 3D-мир**: главная улица с фоновым трафиком, пешеходные переходы, уличные фонари, городские кварталы, динамическая смена времени суток (утро, день, закат, ночь).
- **6 категорий автомобилей**: бюджетные, хэтчбеки, седаны, внедорожники, спорткары и премиум с вращающимися/поворачивающимися колёсами, фарами, стоп-сигналами, динамической грязью и пеной.
- **Реалистичный процесс мойки**: заезд → очередь → встреча сотрудником → смыв высоким давлением → активная пена → ручная чистка → сушка и блеск → оплата и выезд.
- **Персонал**: найм кандидатов, увольнение, назначение на конкретный бокс, обучение навыков, повышение зарплаты, прокачка опыта.
- **Конкурент TURBO SHINE**: полноценная автомойка через дорогу со своими боксами, сотрудниками, очередью, скидочными акциями и аналитикой сравнения доли рынка.
- **Экономика и улучшения**: расширение до 4 боксов, мойка высокого давления, нано-пена, турбосушка и воск, VIP-зона ожидания, солнечные панели и рециркуляция воды, расширение очереди, настройка цен и рекламные кампании.
